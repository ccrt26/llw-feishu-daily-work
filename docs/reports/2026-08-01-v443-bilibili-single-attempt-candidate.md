# LLW Personal Assistant V4.4.3 候选报告

日期：2026-08-01

## 结论

V4.4.3 将 B 站来源策略收口为“一次尝试、明确原因、用户自行重发”。此前临时加入的
网络/媒体失败自动二次调用已删除。手机分享链接规范化、严格来源校验、任务真正结束、
独立 B 站任务、ASR/画面/AI 成功链和 Writer 权限边界全部保留。

## 变更范围

- 安全接受 B 站手机视频分享链接并去除追踪参数；
- 保留 B 站 adapter 与本地复核的固定白名单诊断；
- 删除 B 站自动第二次来源调用；
- 按链接、访问、媒体、超限和本地安全复核类别返回安全原因；
- `任务结束`、`当前任务已结束` 与后台 Task Session 状态一致；
- 增加微信纵向单次失败和“结束旧任务后独立视频”合同。

## 版本说明

V4.4.3 是组件维护版本。私有 `llw-personal-assistant` Skill 内容未修改，因此
生产 Skill manifest 与模型入库元数据版本继续使用 `4.4.0`；配置 Schema 继续使用
V7。二者都不应为了组件补丁被无意义迁移。

## 安全边界

失败回复不包含路径、哈希、完整链接、站点原始响应、标识或堆栈。来源失败时不调用
ASR、AI 或 Writer，不确认写入，并清理本轮公开视频暂存目录。
